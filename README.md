# Next CRUD

Uma aplicação simples que implementa as quatro operações (criação, consulta, atualização e remoção) de um cliente.

A simple application that register, search, update and delete a customer.

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Running

Para rodar a aplicação em modo desenvolvimento, execute o seguinte comando:

```bash
npm run dev
```

Agora é só abrir o endereço [http://localhost:3000](http://localhost:3000) no seu browser.
